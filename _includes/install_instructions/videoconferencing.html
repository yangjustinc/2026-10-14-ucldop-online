Set up Microsoft Teams

The workshop will be delivered online using Microsoft Teams. Please make sure that you can join a Teams meeting on the computer you will use for the workshop before your first session. UCL participants can use the Teams desktop app or join through a supported web browser. If you prefer the desktop app, it is available from the Microsoft Teams download page.

Joining instructions will be sent to registered participants before the workshop. Please test your audio before the session and, if possible, use headphones or a headset to reduce echo and background noise.

Set up your workspace

Like other Carpentries workshops, you will learn by coding along with the Instructors. You will therefore need to see both Microsoft Teams and the software you are working in, such as RStudio, JupyterLab, or your web browser. We recommend one of the following arrangements:

  • Two monitors: use one monitor for Teams and the other for the software you are working in.
  • Two devices: use a second device for Teams and your main computer for coding.
  • Divide your screen: arrange Teams and your coding environment side by side, or practise switching between them using keyboard shortcuts.

This Carpentries blog post includes further guidance on arranging your screen for an online coding workshop.
