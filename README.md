# Reproducible Data Analysis for Mental Health Research

This repository contains the website for **Reproducible Data Analysis for Mental Health Research**, a self-organised Carpentries **Mix & Match** workshop series for PhD students, postdoctoral researchers, and other research staff in the UCL Division of Psychiatry.

The workshop runs as four online half-day sessions on **14 October, 21 October, 28 October, and 4 November 2026**, from **09:30–13:00 (Europe/London)**.

## Workshop website

https://yangjustinc.github.io/2026-10-14-ucldop-online/

## Curriculum

The series uses selected episodes from two official Software Carpentry lessons:

- [R for Reproducible Scientific Analysis](https://swcarpentry.github.io/r-novice-gapminder/)
- [Plotting and Programming in Python](https://swcarpentry.github.io/python-novice-gapminder/)

The R and Python strands each begin at introductory level and progress through data manipulation, visualisation, reproducible reporting, and core programming practices. Learners are encouraged to attend all four sessions for maximum benefit.

## Delivery

The workshop is delivered online via Microsoft Teams. Optional unstaffed workspace is available at UCL Maple House for learners who would prefer to join from the office. Full logistics, setup instructions, the detailed schedule, registration information, and collaborative notes are provided on the workshop website.

## Carpentries workshop template

This site is based on [The Carpentries workshop template](https://github.com/carpentries/workshop-template) and follows Carpentries conventions for self-organised workshops. It is registered as a **Mix & Match** workshop because it combines selected material from the R and Python Software Carpentry curricula rather than delivering a standard core curriculum in full.

Site configuration and learner-facing information are maintained in the `gh-pages` branch.
